# Petualangan Bangun Datar

Aplikasi edukasi React + TypeScript untuk belajar bangun datar lewat peta petualangan.

## Menjalankan aplikasi

1. Buka folder proyek ini di Visual Studio Code.
2. Buka Terminal di folder proyek.
3. Jalankan `npm install`.
4. Jalankan `npm run dev`, lalu buka alamat yang ditampilkan.

## Fitur

- Peta dengan 30 tombol level; level terkunci dapat diketuk untuk melihat cara membukanya.
- Kuis untuk setiap level, dengan umpan balik dan kesempatan mencoba lagi.
- Level terbuka berurutan setelah jawaban benar.
- Progres, level terbuka, dan bintang tersimpan di browser.
- Navigasi Beranda, Peta, Prestasi, Materi, dan Profil.
- Tombol misi dan koleksi pada peta menampilkan progres terkini.

Gambar peta berada di `public/adventure-map.jpg`. Titik level ditampilkan sebagai lapisan interaktif di atas gambar.
